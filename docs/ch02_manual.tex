\section{使用者操作說明}

\subsection{主畫面}

程式啟動後會建立主要繪圖視窗，中央區域為 Canvas，使用者可以直接在其中進行繪圖與物件選取。
視窗底部的狀態列會顯示目前使用的工具、繪圖樣式、滑鼠在 Canvas 中的位置，以及目前 Canvas 的尺寸。
預設工具為 Pencil，Grid 則預設使用 Lines 模式。

在 Canvas 上按下滑鼠右鍵可以開啟階層式選單，切換工具或調整各種繪圖屬性。
圖~\ref{fig:main-window} 為程式的主畫面。

\subsection{繪圖屬性}

程式可以分別設定圖形的 Stroke、Fill、Point 與 Text 屬性。

Stroke 可調整顏色、線寬，以及 MITER、BEVEL、ROUND 三種 Line Join；
線段端點則提供 BUTT、SQUARE、ROUND 三種 Line Cap。
Fill 支援 \lstinline|OUTLINE|、\lstinline|FILLED| 與 \lstinline|ADVANCED| 三種模式，
其中 \lstinline|ADVANCED| 會分別處理填色與自製的粗線幾何。

Point Size 與 Stroke Width 可以透過右鍵選單調整，
也可以利用中括號快捷鍵快速增加或減少大小。
文字則可以選擇 FreeGLUT 或自訂的點陣字型。


\subsection{階層式選單}

在 Canvas 上按下滑鼠右鍵即可開啟主選單。
選單依功能分成數個子選單：

\begin{itemize}
    \item \textbf{File}：建立文件、開啟文件、儲存及輸出圖片。
    \item \textbf{Edit}：Undo、Redo 與清空目前畫布。
    \item \textbf{Tools}：切換目前使用的繪圖或選取工具。
    \item \textbf{Stroke}：設定線條顏色、寬度、Join 與 Cap。
    \item \textbf{Fill}：設定填滿模式與填色。
    \item \textbf{Point}：調整 Point Size。
    \item \textbf{Text}：選擇文字字型。
    \item \textbf{Grid}：切換格線的顯示模式。
\end{itemize}

常用功能也提供鍵盤快捷鍵，因此不需要每次都透過選單操作。

滑鼠左鍵主要用於繪圖與物件選取，右鍵則用來開啟階層式選單。
使用 Select 時，若多個物件互相重疊，程式會優先選取視覺上最上層的物件；
點擊空白處或按下 Esc 即可取消目前的選取。

Line、Rectangle 與 Ellipse 在拖曳期間可以按住 Shift 限制形狀；
Polygon 則可以利用雙擊或 Enter 完成，並可使用 Backspace 移除上一個頂點、
Esc 取消本次繪製。


\subsection{視窗與對話框}

程式可以同時建立多個繪圖視窗，每個視窗都有獨立的 Document 與 Undo/Redo 紀錄，
彼此之間的繪圖內容不會互相影響。

文字輸入、檔名輸入與確認操作會另外開啟對話框。
當 Modal Dialog 開啟時，其他繪圖視窗會暫停接收使用者輸入，
避免在對話框尚未處理完成時誤操作背景視窗。

若目前文件仍有尚未儲存的修改，
執行 New、Load 或 Close 等可能捨棄目前內容的操作時，
程式會先顯示確認視窗，再由使用者決定是否繼續。
