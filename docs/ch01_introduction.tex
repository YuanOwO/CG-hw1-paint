\section{專案介紹}
\label{sec:introduction}

\subsection{作業目標}

本次作業的目標是使用 OpenGL 與 GLUT 實作一套互動式 2D Drawing Panel。
使用者需要能夠透過滑鼠與鍵盤在視窗中繪製基本幾何圖形與文字，
並利用階層式選單選擇繪圖工具及調整顏色、線寬、點大小、填滿模式與字型等屬性。

除了基本繪圖功能外，作業也要求程式處理 keyboard、mouse、window 與 motion event，
使使用者可以透過滑鼠操作決定圖形的位置與形狀。
在進階要求中，程式還需要利用 idle event 或 timer 保存 Color Buffer，
並在 display event 發生時還原已保存的畫面內容；
此外也包含儲存 Color Buffer、輸入文字，以及利用 Grid 或 Scale 顯示位置與尺寸等功能。

\subsection{系統概述}

本次實作的程式命名為 \textbf{Graphtoria}，
是一套以 OpenGL 與 FreeGLUT 實作的 2D 繪圖程式。

程式目前提供 Select、Point、Pencil、Line、Rectangle、Ellipse、Polygon 與 Text 等工具。
使用者可以利用滑鼠直接在 Canvas 上建立與選取物件，
並透過右鍵階層式選單調整 Stroke、Fill、Point Size、Text Font 與 Grid 等繪圖屬性。

除了基本繪圖功能外，程式也支援 Undo/Redo、物件刪除、多視窗、Grid、
文字輸入對話框，以及 PPM 圖片輸出。
Select 工具可以選取畫面中最上層的圖形或文字，
並顯示目前物件的選取範圍；
刪除操作也會加入 Undo/Redo 紀錄，因此可以復原。

在文字方面，除了 FreeGLUT 內建字型外，
程式也支援自訂的點陣字型與 UTF-8 中文字元顯示。
畫面內容則可以透過 Color Buffer 保存與還原，
並可將目前 Canvas 輸出為 PPM 圖片。

整體而言，程式除了完成作業要求的 drawing panel 功能外，
也加入文件操作、物件選取與較完整的視窗互動功能。
各功能的使用方式將於下一章介紹，
程式內部的模組分工與資料流程則於第~\ref{sec:architecture} 章說明。
